# Signaler une vulnérabilité

Le canal privilégié est GitHub Private Vulnerability Reporting. Une fois la fonction activée, utiliser **Security → Advisories → Report a vulnerability**. Fournir la version, le comportement observé et des étapes reproductibles avec des données fictives. Garder les détails de la vulnérabilité hors des issues publiques. Omettre les clés, jetons, données patients et sauvegardes privées.

Avant publication, le responsable du dépôt doit activer **Private vulnerability reporting** dans **Settings → Advanced Security** et vérifier que le formulaire de signalement est accessible depuis la page des avis de sécurité. [Procédure officielle GitHub](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)
